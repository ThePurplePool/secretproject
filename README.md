# Anti-Scam Uzbekistan — Интерактивная платформа практической защиты

Платформа практической выработки рефлексов противодействия социальной инженерии, фишингу и кибермошенничеству для граждан Республики Узбекистан.

В отличие от классических LMS, тестов или теоретических лекций, платформа погружает пользователя в **реалистичную искусственную ситуацию атаки**, создаёт **ограничение по времени**, требует **принятия решения** и визуализирует **цепочку реальных последствий** и симулированный финансовый ущерб.

---

## 🚀 Основные возможности MVP

1. **Scenario UI Engine**:
   - Реалистичные интерфейсы: **Telegram**, **SMS**, **Email**, **Web Browser**, **Banking App**, **Social Network**, **Delivery/Marketplace**, **Phone Call**.
   - Generic-but-familiar UI с узнаваемыми национальными и пользовательскими паттернами.

2. **Core Loop & Consequence Engine**:
   - Таймер с нарастающим психологическим давлением (фразы и визуальные предупреждения на 15, 8 и 3 секундах).
   - Цепочка последствий: `Файл → Вредоносный код → Компрометация устройства → Доступ к данным → Финансовый риск`.
   - Виртуальный баланс (10 000 000 сум) с фиксацией симулированного ущерба.

3. **Система уровней и цифровой сертификации**:
   - **Уровень 1 (Распознай)** → Сертификат *Anti-Scam Basic*.
   - **Уровень 2 (Защити)** → Сертификат *Anti-Scam Defender*.
   - **Уровень 3 (Консультант)** → Сертификат *Anti-Scam Consultant* (разбор инцидентов близких и коллег).
   - Образовательная механика сообщества: «Помогите защитить ещё 5 человек» с персональными ссылками и отслеживанием.

4. **AI Voice Scam Simulator**:
   - Provider-agnostic архитектура (`VoiceProvider`).
   - Имитация звонков лжеследователей МВД и лжесотрудников безопасности банков с озвучиванием (Web Speech API / TTS).

5. **Модуль сообщений о мошенничестве и Fraud Intelligence**:
   - Форма приёма номеров телефонов, Telegram-ботов, URL, карт и описания инцидента.
   - Rule-based корреляция индикаторов в **Scam Clusters** (автоматическое выявление синдикатов).

6. **Admin Intelligence Panel**:
   - Сводные KPI (пользователи, пройденные ситуации, процент ошибок, среднее время ответа, симулированный ущерб).
   - Управление публикацией сценариев.
   - Реестр инцидентов и выданных сертификатов.

## 🛠 Технологический стек

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- **Backend**: Node.js, Express, TypeScript, Better-SQLite3.
- **База данных**: SQLite (с готовностью миграции схемы на PostgreSQL).
- **Развёртывание**: Docker, Docker Compose, прямой запуск через npm.

---

## 📦 Быстрый старт

### Требования
- Node.js 20+
- npm 10+
- (Опционально) Docker и Docker Compose

### 1. Установка зависимостей

```bash
# В корне проекта
npm --prefix server install
npm --prefix client install
```

### 2. Сборка проекта

```bash
npm --prefix server run build
npm --prefix client run build
```

### 3. Запуск

#### Режим разработки:
В двух терминалах:
```bash
# Терминал 1: API сервер (порт 5000)
npm run dev:server

# Терминал 2: Frontend клиент (порт 3000)
npm run dev:client
```

#### Запуск готового приложения:
```bash
npm run build:client
npm run build:server
npm start
```
Приложение откроется на [http://localhost:5000](http://localhost:5000).

---

## 🐳 Запуск через Docker

```bash
docker compose up --build
```
Сервис будет доступен на [http://localhost:5000](http://localhost:5000).

## 🛡️ Безопасность и приватность

- Все симуляции являются учебными и контролируемыми.
- **Никаких реальных вредоносных нагрузок:** сценарии с файлами используют безопасную визуальную демонстрацию.
- **Никаких реальных конфиденциальных данных:** система не запрашивает и не хранит реальные данные банковских карт, пароли или OTP-коды граждан.
- Пользовательские загрузки и отчёты экранируются и не исполняются на сервере.
